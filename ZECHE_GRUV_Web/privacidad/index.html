Política de privacidad

Última actualización: 14 de octubre de 2026

ZECHE GRUV es un sello y productora musical independiente de Buenos Aires, Argentina. Esta página cuenta qué datos usamos en zechegruv.com, el portal de artistas y ZG PASS, para qué y cómo cuidarlos.

Qué datos usamos

  • Portal de artistas: tu nombre, tu mail y lo que subís o escribís (audios, letras, notas y aprobaciones de tus canciones), para acompañar el trabajo de cada tema.
  • ZG PASS (entradas): nombre y mail de quien compra, para enviar la entrada y avisos del evento. Los pagos los procesa Mercado Pago: nunca vemos ni guardamos datos de tarjetas.
  • Medición: estadísticas anónimas de uso de la página (Google Analytics) para mejorarla.

Google Calendar

El panel interno de ZECHE GRUV puede conectarse al Google Calendar del estudio, solo con permiso expreso de su dueño, para ver horarios libres y mover o crear sesiones de mezcla, mastering y entregas. Esos datos se usan únicamente para organizar la agenda del estudio: no se comparten, no se venden y no se usan para publicidad. El uso de la información recibida de las APIs de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado. El permiso se puede quitar en cualquier momento desde myaccount.google.com/permissions.

Con quién se comparten

Con nadie para fines comerciales. Usamos proveedores que guardan o procesan los datos por nosotros (alojamiento web, base de datos, envío de mails, pagos y almacenamiento de archivos), solo para que el servicio funcione.

Tus derechos

Podés pedir ver, corregir o borrar tus datos escribiendo a zechegruv@gmail.com. Te respondemos a la brevedad.
